# 使用 easygit

## 打开、克隆或初始化

启动后，可以从首页选择三种方式开始。已有项目打开后，也可以点击顶部项目名称，在打开仓库窗口中进入克隆或初始化；`Ctrl + K` 中提供相同入口。

### 打开本地仓库

点击“打开仓库”，选择或输入项目目录，再点击“打开仓库”。支持普通 Git 仓库和已有 worktree；不需要选择 `.git` 目录本身。最近项目会保存在本机，可以从侧栏切换。

### 克隆仓库

1. 点击“克隆仓库”。
2. 填写仓库地址，例如 `https://github.com/owner/project.git` 或 `git@github.com:owner/project.git`；也支持本机仓库的绝对路径。
3. 选择已存在的保存位置，并填写一个尚不存在的新文件夹名称。名称会根据仓库地址自动填写，也可以修改。
4. 点击“克隆并打开”。进度中的百分比对应正在接收对象、解析差异或检出文件等当前阶段，完成后自动进入工作台。

克隆时可点击“取消克隆”，等待临时文件清理后重新尝试。失败会保留表单内容，已有同名文件夹不会被覆盖。

### 初始化已有项目

选择“初始化仓库”，指定已有项目文件夹，填写初始分支名称（默认为 `main`），点击“初始化并打开”。现有项目文件会保留，初始化不会自动创建提交。请先检查需要忽略的文件，再选择要暂存和提交的内容。

如果目录已经属于 Git 仓库，请直接使用“打开仓库”。easygit 不会在已有仓库内再初始化嵌套仓库。

## 配置远程地址

打开项目后，点击分支面板的“配置远程仓库”按钮，或通过“偏好设置 → 远程仓库”进入，也可在命令面板搜索“配置远程仓库”。

- **新增**：点击“添加远程仓库”，填写远程名称（通常为 `origin`）和地址，保存即可。
- **修改**：点击对应远程的编辑按钮，更换获取地址。已有独立推送地址会保留并显示在列表中；需要调整多个获取地址或独立推送地址时，请使用 Git 命令。
- **移除**：点击删除按钮，核对远程名称后确认。该操作会移除本地远程配置、对应的远程跟踪分支及上游关联；本地分支、文件和服务器上的仓库会保留。

修改配置前会核对最新值，外部工具已经更改配置时会阻止覆盖；返回列表并刷新后重新操作。后台获取更新期间会暂时禁用配置修改。

保存地址不会自动连接远程服务器。可点击分支面板的“获取更新”检查连接和更新远程分支。首次推送会设置上游，通常使用 `origin`，没有 `origin` 时使用第一个远程；多个远程时可先为当前分支明确设置上游。

## 私有仓库与连接问题

easygit 使用本机 Git 的身份验证方式。HTTPS 仓库可使用已经配置的 Git 凭据管理器，SSH 仓库使用本机 SSH 密钥。不要将密码或访问令牌写入仓库地址。

- **身份验证失败**：检查本机 Git 凭据、账号权限或 SSH 密钥；完成配置后重新获取或克隆。
- **无法连接／超时**：检查网络、VPN 和本机 Git 代理配置。克隆最多等待 30 分钟，也可以主动取消。
- **目标文件夹已存在**：更换新文件夹名称，或者确认目录已经是仓库后直接打开。
- **找不到 Git**：安装 Git 并确保加入 PATH，然后重新启动 easygit。

通知显示主要原因，“操作记录”可查看原始错误详情；可在“布局”中显示该面板。

## 日常提交与同步

1. 在变更列表选择文件，查看差异。
2. 暂存本次要提交的文件，填写提交信息，按 `Ctrl + Enter` 提交。提交只影响本地仓库。
3. 点击提交按钮旁的推送按钮，将当前分支发送到远程。

“获取更新”只更新远程分支信息；“拉取更新”会把上游分支合并到当前分支。拉取发生冲突时，在变更列表打开冲突文件，保存合并结果并暂存，再使用操作提示条完成合并。

## 布局与退出

点击“布局”可以显示、隐藏业务面板；拖动手柄交换位置，拖动边框调整尺寸，面板标题栏可以最大化。侧栏依次提供工作区变更、代码差异、分支、提交记录、项目文件五个入口，点击后会自动显示并定位对应面板，原有排列与尺寸会保留。

关闭窗口会收起到系统托盘。点击托盘图标恢复；需要完全退出或安装更新时，从托盘右键菜单选择“退出 easygit”。
